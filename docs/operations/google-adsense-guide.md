# Google AdSense 審査と導入の手順

ソースコード（`src/app/layout.tsx`）へのAdSenseタグの追加が完了した後の手順をまとめています。

## 1. 本番環境へのデプロイ
今回追加した `<script>` タグを含むコードを、Vercelなどの本番環境へデプロイしてください。
デプロイ後、実際のWebサイトのソースコードを確認し、`<head>` タグ内に `adsbygoogle.js` のスクリプトが存在するか確認します。

## 2. AdSense管理画面での「審査リクエスト」
1. [Google AdSense](https://www.google.com/adsense) にログインします。
2. 左側メニューの「サイト」をクリックします。
3. 今回タグを設置したサイト（`toeic-words.com` など）を選択し、「審査をリクエスト」ボタンをクリックします。
   ※「コードが見つかりました」という表示が出れば、正常にサイト側のタグが読み込まれています。

## 3. 審査結果を待つ
Googleによるサイトのコンテンツおよびポリシー遵守の審査が行われます。
- 期間は通常数日〜2週間程度です。
- 結果はAdSenseに登録したメールアドレスに通知されます。

## 4. `ads.txt` ファイルの設置（警告が出た場合）
AdSenseの管理画面の上部に「要注意 - 収益に重大な影響が出ないよう、ads.txt ファイルの問題を修正してください。」という警告が出ることがあります。
その場合は以下の手順で設定を行います。

1. AdSense管理画面から `ads.txt` に記載するテキスト（1行）をコピーします。
2. プロジェクトの `public/` フォルダ内に `ads.txt` という名前のファイルを新規作成します。
3. コピーした内容を `public/ads.txt` に貼り付けて保存します。
   （例：`google.com, pub-3016015645741811, DIRECT, f08c47fec0942fa0`）
4. 再度、本番環境へデプロイします。
   （ブラウザで `https://www.toeic-words.com/ads.txt` にアクセスして内容が表示されれば完了です。警告は数日後に自動で消えます。）

## 5. 広告の表示設定（審査通過後）
審査に通過すると、サイト上に広告を配信できるようになります。

### 自動広告を利用する場合（おすすめ）
AdSense管理画面の「広告」>「サマリー」から該当サイトの「編集（鉛筆アイコン）」をクリックし、「自動広告」をオンにします。
Googleがサイトのレイアウトを解析し、最適な場所に自動で広告を表示してくれます。（今回追加したタグのみで動作します）

### 手動で広告ユニットを配置する場合
特定の場所（一覧の間や記事の終わりなど）に意図して広告を出したい場合は、AdSense管理画面で「広告ユニット」を作成します。
Next.js（React）で手動広告を配置する場合は、専用のコンポーネントを作成してコードを埋め込む作業が別途必要になります。
